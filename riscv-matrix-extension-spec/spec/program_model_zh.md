## CSR 概览

矩阵扩展新增了 8 个二维矩阵寄存器和 8 个 CSR。

| 地址 | 权限 | 名称 | 描述 |
| --- | --- | --- | --- |
| `0x802` | `URW` | `xmcsr` | 矩阵控制与状态寄存器 |
| `0x803` | `URW` | `mtilem` | m 方向上的 tile 长度 |
| `0x804` | `URW` | `mtilen` | n 方向上的 tile 长度 |
| `0x805` | `URW` | `mtilek` | k 方向上的 tile 长度 |
| `0xcc0` | `URO` | `xmisa` | 矩阵指令子集 |
| `0xcc1` | `URO` | `xtlenb` | tile 寄存器大小，单位字节，`ROWNUM * TRLEN / 8` |
| `0xcc2` | `URO` | `xtrlenb` | tile 寄存器单行大小，单位字节，`TRLEN / 8` |
| `0xcc3` | `URO` | `xalenb` | 累加寄存器大小，单位字节，`ROWNUM^2 * ELEN / 8` |

矩阵扩展还为 `xmxrm`、`xmsat`、`xmfflags`、`xmfrm`、`xmsaten` 提供了独立 CSR 地址。这些字段同时也映射在 `xmcsr` 中，便于独立访问。

| 地址 | 权限 | 名称 | 描述 |
| --- | --- | --- | --- |
| `0x806` | `URW` | `xmxrm` | 定点舍入模式 |
| `0x807` | `URW` | `xmsat` | 定点累积饱和标志 |
| `0x808` | `URW` | `xmfflags` | 浮点累积异常标志 |
| `0x809` | `URW` | `xmfrm` | 浮点舍入模式 |
| `0x80a` | `URW` | `xmsaten` | FP8 或整数矩阵乘指令的饱和模式使能 |

## 矩阵寄存器

矩阵扩展增加了 4 个架构态 **Tile Registers**（`tr0`-`tr3`），用于保存输入 tile 矩阵；同时增加了 4 个架构态 **Accumulation Registers**（`acc0`-`acc3`），用于保存输出累加矩阵。

**Tile Register** 具有固定的 `TLEN` 位状态，每一行宽度为 `TRLEN` 位。因此，在逻辑上，每个 tile 寄存器包含 `TLEN / TRLEN` 行。每个 tile 寄存器由 `[M x K]` 个元素组成，其中 `K = TRLEN / element width`。

**Accumulation Register** 具有固定的 `ALEN` 位状态，每一行宽度为 `ARLEN` 位。因此，在逻辑上，每个累加寄存器包含 `ALEN / ARLEN` 行，这个值等于 `TLEN / TRLEN`。

`ARLEN` 由 `TLEN / TRLEN * ELEN` 推导得到，这意味着累加寄存器中的元素宽度不应大于 `ELEN`。

当 `ELEN = 32 bit` 且 `TLEN = 512 bit` 时，矩阵寄存器大小变化如下：

| --- | --- | --- | --- | --- | --- | --- |
| 32 bit | 512 | 32 | 8192 | 16x1 | 16x16 | 外积 |
| 32 bit | 512 | 64 | 2048 | 8x2 | 8x8 |  |
| 32 bit | 512 | 128 | 512 | 4x4 | 4x4 |  |
| 32 bit | 512 | 256 | 128 | 2x8 | 2x2 |  |
| 32 bit | 512 | 512 | 32 | 1x16 | 1x1 | 内积 |
| 16 bit | 512 | 32 | 8192 | 16x2 | 16x16 |  |
| 16 bit | 512 | 64 | 2048 | 8x4 | 8x8 |  |
| 16 bit | 512 | 128 | 512 | 4x8 | 4x4 |  |
| 16 bit | 512 | 256 | 128 | 2x16 | 2x2 |  |
| 16 bit | 512 | 512 | 32 | 1x32 | 1x1 |  |
| 8 bit | 512 | 32 | 8192 | 16x4 | 16x16 |  |
| 8 bit | 512 | 64 | 2048 | 8x8 | 8x8 |  |
| 8 bit | 512 | 128 | 512 | 4x16 | 4x4 |  |
| 8 bit | 512 | 256 | 128 | 2x32 | 2x2 |  |

## 矩阵 ISA 寄存器 `misa`

只读的 `XLEN` 位 CSR `misa` 用于描述当前硬件实现所支持的矩阵算术特性。

| 位段 | 特性 | 支持类型 |
| --- | --- | --- |
| `XLEN-1` | `miew` | 可选 |
| `XLEN-2` | `mfew` | 可选 |
| `XLEN-3` | `mfic` | 可选 |
| `XLEN-4:10` | `0` | 保留 |
| `9` | `mmf8f32` | 必选 |
| `8` | `mmf32f64` | 可选 |
| `7` | `mmbf16f32` | 必选 |
| `6` | `mmf16f32` | 必选 |
| `5` | `mmf8bf16` | 必选 |
| `5` | `mmf8f16` | 必选 |
| `4` | `mmf64f64` | 可选 |
| `3` | `mmf32f32` | 可选 |
| `2` | `mmf16f16` | 必选 |
| `1` | `mmi8i32` | 必选 |
| `0` | `mmi4i32` | 可选 |

对于每一个字段，值为 `0` 表示对应特性不支持，值为 `1` 表示对应特性支持。

- 对于 `mmi4i32` 字段：
  - 值为 `1` 表示支持对应的 int4/uint4 八倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `(s/u)int4`，目标操作数为 `int32`。
  - 该字段对硬件实现来说是可选的。

- 对于 `mmi8i32` 字段：
  - 值为 `1` 表示支持对应的 int8/uint8 四倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `(s/u)int8`，目标操作数为 `int32`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmf16f16` 字段：
  - 值为 `1` 表示支持对应的 fp16 不扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp16`，目标操作数为 `fp16`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmf32f32` 字段：
  - 值为 `1` 表示支持对应的 fp32 不扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp32`，目标操作数为 `fp32`。
  - 该字段对硬件实现来说是可选的。

- 对于 `mmf64f64` 字段：
  - 值为 `1` 表示支持对应的 fp64 不扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp64`，目标操作数为 `fp64`。
  - 该字段对硬件实现来说是可选的。

- 对于 `mmf8f16` 字段：
  - 值为 `1` 表示支持对应的 fp8 两倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 fp8（`E4M3` 和 `E5M2`），目标操作数为 `fp16`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmf8bf16` 字段：
  - 值为 `1` 表示支持对应的 fp8 两倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 fp8（`E4M3` 和 `E5M2`），目标操作数为 `bf16`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmf16f32` 字段：
  - 值为 `1` 表示支持对应的 fp16 两倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp16`，目标操作数为 `fp32`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmbf16f32` 字段：
  - 值为 `1` 表示支持对应的 bf16 两倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `bf16`，目标操作数为 `fp32`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mmf32f64` 字段：
  - 值为 `1` 表示支持对应的 fp32 两倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp32`，目标操作数为 `fp64`。
  - 该字段对硬件实现来说是可选的。

- 对于 `mmf8f32` 字段：
  - 值为 `1` 表示支持对应的 fp32 四倍扩宽矩阵乘法指令。
  - 该字段的源操作数类型为 `fp8`，目标操作数为 `fp32`。
  - 该字段对硬件实现来说是必选的。

- 对于 `mfic` 字段：
  - 值为 `1` 表示支持整数与浮点扩展之间的转换。
  - 该字段对硬件实现来说是可选的。

- 对于 `mfew` 字段：
  - 值为 `1` 表示支持浮点逐元素扩展（包括算术指令和转换指令）。
  - 该字段对硬件实现来说是可选的。

- 对于 `miew` 字段：
  - 值为 `1` 表示支持整数逐元素扩展（包括算术指令和转换指令）。
  - 该字段对硬件实现来说是可选的。

## 矩阵 Tile 大小寄存器 `mtilem / mtilek / mtilen`

只读的 `XLEN` 位 CSR `mtilem / mtilek / mtilen` 只能通过 `msettile{m|k|n}{i}` 指令更新。

这三个寄存器保存 3 个无符号整数，用来指定 tile 化矩阵的形状。

## 矩阵控制与状态寄存器 `mcsr`

`xmcsr` CSR 是一个 `WARL` 类型的可读写寄存器。`Bits[XLEN-1:12]` 为保留位，写入时应为零。

`mcsr` 寄存器包含 5 个字段。独立 CSR `xmxrm`、`xmsat`、`xmfflags`、`xmfrm`、`xmsaten` 也可以通过 `xmcsr` 中对应字段访问。

### `xmcsr` 寄存器布局

| 位段 | 名称 | 描述 |
| --- | --- | --- |
| `XLEN-1:12` | `0` | 保留位，非零无效 |
| `11` | `xmsaten` | 整数和 fp8 的饱和模式 |
| `10:8` | `xmfrm` | 浮点算术指令舍入模式 |
| `7:3` | `xmfflags` | 浮点算术指令累积异常标志 |
| `2` | `xmsat` | 定点算术指令累积饱和标志 |
| `1:0` | `xmxrm` | 定点算术指令舍入模式 |

## 矩阵定点舍入模式 `xmxrm`

`xmxrm` 字段表示定点指令的舍入模式。假设舍入前结果为 `v`，其中有 `d` 位需要被舍弃，则舍入后的结果为：

```text
(v >> d) + r
```

其中 `r` 的取值依赖于舍入模式，如下表所示：

| mrm | 助记符 | 含义 | 舍入增量 r |
| --- | --- | --- | --- |
| `00` | `RNU` | 就近向上舍入（加 `+0.5 LSB`） | `v[d-1]` |
| `01` | `RNE` | 就近舍入到偶数 | `v[d-1] & (v[d-2:0] != 0 \| v[d])` |
| `10` | `RDN` | 向下舍入（截断） | `0` |
| `11` | `ROD` | 舍入为奇数（将被舍弃位 OR 到最低位） | `!v[d] & v[d-1:0] != 0` |

下面的舍入函数用于后续指令描述：

```text
roundoff_unsigned(v, d) = (unsigned(v) >> d) + r
roundoff_signed(v, d)   = (signed(v) >> d) + r
```

## 矩阵定点饱和标志 `xmsat`

矩阵定点饱和标志 `xmsat` 是一个可读写的单比特标志，位于 `xmsat[0]`，用于指示某条定点指令是否因目标格式宽度不足而对输出值进行了饱和。

高位 `xmsat[XLEN-1:1]` 应写零。

`xmsat` 拥有独立的 CSR 地址，便于单独访问；同时它也映射在 `xmcsr` 的对应字段中。

## 矩阵浮点异常标志 `xmfflags`

矩阵浮点异常标志 `xmfflags` 是一个 5 位可读写字段，位于 `xmfflags[4:0]`。高位 `xmfflags[XLEN-1:5]` 应写零。

`xmfflags` 拥有独立 CSR 地址，便于单独访问；同时它也映射在 `xmcsr` 的对应字段中。

浮点矩阵乘法和浮点逐元素指令会更新 `xmfflags` 中的累积异常标志。

| 位 | 含义 |
| --- | --- |
| `0` | `NX` |
| `1` | `UF` |
| `2` | `OF` |
| `3` | 预留给未来使用 |
| `4` | `NV` |

## 矩阵浮点舍入模式 `xmfrm`

矩阵浮点舍入模式 `xmfrm` 是一个 3 位可读写字段，位于 `xmfrm[2:0]`。高位 `xmfrm[XLEN-1:3]` 应写零。

`xmfrm` 拥有独立 CSR 地址，便于单独访问；同时它也映射在 `xmcsr` 的对应字段中。

| mfrm | 助记符 | 含义 |
| --- | --- | --- |
| `000` | `RNE` | 舍入到最近值，遇到中间值取偶 |
| `001` | `RTZ` | 向零舍入 |
| `010` | `RDN` | 向负无穷舍入 |
| `011` | `RUP` | 向正无穷舍入 |
| `100` | `RMM` | 舍入到最近值，遇到中间值取最大幅值 |
| `101` |  | 非法 |
| `110` |  | 非法 |
| `111` |  | 非法 |

如果 `xmfrm` 被设置成非法值（`101`-`111`），那么后续任何使用动态舍入模式执行的浮点操作都将触发非法指令异常。

## 矩阵饱和模式使能 `xmsaten`

矩阵饱和模式 `xmsaten` 是一个可读写的单比特字段，位于 `xmsaten[0]`，用于定义当运算结果为 fp8 或整数时的饱和模式。

高位 `xmsaten[XLEN-1:1]` 应写零。

`xmsaten` 拥有独立 CSR 地址，便于单独访问；同时它也映射在 `xmcsr` 的对应字段中。

| msaten | 含义 |
| --- | --- |
| `0` | 非饱和模式 |
| `1` | 饱和模式 |

从其他格式转换到目标格式时，首先会执行舍入，以将尾数位数缩减到目标 FP8 格式要求的位数。之后，如果舍入后的幅值超过目标格式允许的最大幅值：

```text
if msaten = 1:
    fp8 转换：生成目标 FP8 格式的最大正规数幅值
    mmacc 操作：结果执行饱和
    整数算术操作：结果执行饱和

if msaten = 0:
    fp8 转换：
        E4M3 目标格式：生成 NaN
        E5M2 目标格式：生成 Infinity
    mmacc 操作：忽略溢出，结果回绕
    整数算术操作：忽略溢出，结果回绕
```

## `mstatus` 和 `sstatus` 中的矩阵上下文状态

应在 `mstatus` 中增加一个 2 位的矩阵上下文状态字段 `MS`，并在 `sstatus` 中提供其镜像。它的定义与向量上下文状态字段 `VS` 类似。

| ms[1:0] | 含义 |
| --- | --- |
| `00` | 全关闭（All Off） |
| `01` | 初始（Initial） |
| `10` | 干净（Clean） |
| `11` | 脏（Dirty） |

当 `MS` 被设置为 `off` 时，任何矩阵指令执行，或者任何矩阵 CSR 访问，都会触发非法指令异常。

如果 `MS` 被设置为 `initial` 或 `clean`，那么执行任何会修改矩阵状态的指令后，`MS` 都会变为 `dirty`。

实现可以利用 `Initial` 状态的活跃信息来影响低功耗状态的选择。
